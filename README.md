## Основное задание

### Решение

**Файл с реализацией `selectProducts`:**

`src/main/kotlin/lab2/ProductSelection.kt`

**Как работает функция и почему выбран такой способ обработки данных?**

Функция сначала создаёт хеш-индекс каталога `HashMap<Long, Product>` через `associateByTo`, чтобы находить товар по идентификатору без последовательного поиска по каталогу. Рекомендации преобразуются в `LinkedHashSet`, исключения — в `HashSet`. Затем функция обходит уникальные рекомендации, проверяет наличие и доступность товара, отсутствие в исключениях и добавляет подходящие товары в результат.

**Как сохраняются порядок рекомендаций и уникальность товаров? Как обрабатываются исключённые, недоступные и неизвестные товары?**

`LinkedHashSet` сохраняет порядок первого появления идентификаторов и устраняет повторы. Неизвестные ID пропускаются, недоступные товары (`available == false`) и товары из множества исключений не добавляются. Входные списки не изменяются.

### Сложность

Обозначения:

- `p` — число товаров в каталоге;
- `r` — число идентификаторов в рекомендациях;
- `e` — число идентификаторов в исключениях.

**Время выполнения:**

**Ожидаемое O(p + r + e)**: построение индекса каталога — O(p), множества рекомендаций — O(r), множества исключений — O(e), обход уникальных рекомендаций — не более O(r). Оценка предполагает в среднем O(1) для операций с хеш-таблицами (при корректном хешировании и без патологических коллизий).

**Дополнительная память:**

**O(p + r + e)** на индекс каталога, множество уникальных рекомендаций и множество исключений. Дополнительно **O(k)** для результирующего списка, где `k ≤ min(p, r)` — число выбранных товаров. Входные списки не копируются целиком и не изменяются.

В таблице указываются названия тестов или ссылки на них. Один тест может проверять несколько условий.

| Что проверяется | Тесты |
| --- | --- |
| Обычная подборка; порядок рекомендаций отличается от порядка каталога | `selectsAvailableProductsInRecommendationOrder`, `preservesRecommendationOrderRegardlessOfCatalogOrder` |
| Повторяющиеся рекомендации и исключения | `removesDuplicateRecommendations`, `ignoresDuplicateAndUnknownExclusions` |
| Недоступные, исключённые и неизвестные товары | `skipsUnavailableAndUnknownProducts`, `ignoresDuplicateAndUnknownExclusions`, `selectsAvailableProductsInRecommendationOrder` |
| Пустой каталог, пустые рекомендации, пустые исключения | `returnsEmptyListForEmptyCatalog`, `returnsEmptyListWhenThereAreNoRecommendations`, `includesAllRecommendedAvailableProductsWhenExclusionsAreEmpty` |
| Ни один товар не подходит | `returnsEmptyListWhenNoProductsMatch` |
| Входные данные не изменяются; повторные вызовы независимы | `doesNotModifyInputLists`, `repeatedCallsHaveIndependentResults` |
